# 完整剪辑流程复盘（以摩旅 vlog 为例）

## 任务背景
- 素材：百度网盘目录 `/骑车/action5pro`，31 个文件、约 374GB，全部为 DJI Action5Pro 第一视角骑行（画面下方有车把/仪表/导航）。
- 约束：用户本地硬盘不足，不能下载；由助手侧完成下载与全部后期，只交付成片。
- 成片定位：朋友圈、治愈风景、横屏 16:9、约 46 秒、慢节奏、纯背景音乐、无解说无现场声、无任何字幕文字、冷色调氛围。

## 全流程（9 步）

### 1. 需求确认（开工前一次问清）
用途/平台、画幅、时长、节奏、音频（纯 BGM/现场声/解说）、字幕、色调风格。本次结论见上。

### 2. 素材获取（不占用户本地）
- 先确认网盘 MCP 无下载/云剪辑能力（见 troubleshooting #1）。
- 用官方 Linux 客户端、单并发下载到持久工作目录 `./downloads`（98–112MB/s）。
- `download_watchdog.sh` 守护：系统重置自动 recover、客户端退出自动重启、内存低于 1200MB 主动重启防 OOM；断点续传。
- 下完用 ffprobe 逐个核对可解码、时长完整，31/31 不缺件。

### 3. 逐个看片
- `make_grid.py` 对每个文件抽 8 帧拼网格，全部看过。
- 甄别：白天为山区多云漫射光——青山、峡谷、沿河公路、连续弯道、林间、隧道、高架桥；无夕阳黄金时刻。
- 排除：夜间骑行、收费站、城镇高楼、手机特写、推车、落石路段。

### 4. 选镜头（叙事 + 多样）
- 情绪线：抓眼开场 → 沿河/林间建立 → 弯道/峡谷发展 → 开阔大景高潮 → 山间公路收尾留白。
- 强制场景多样：远近、明暗（隧道）、水、桥、林荫、弯道、开阔交替，避免全是同质"车把+前方"。
- 每个镜头记录 源文件 + 精确入点（候选帧附近抽密帧定位）。

### 5. 精剪（make_clips.py）
- 统一 1920x1080、30fps；逐镜头/统一调色；每片段 4.6 秒。
- 慢节奏柔和淡接；低内存下分步处理、中断可幂等续跑。

### 6. 字幕
本次无文字（用户明确要求去掉）。需要时用细体白字柔影、Noto CJK、不挡风景。

### 7. 音频
纯 BGM：丢弃现场声；`afade` 淡入 0–2.5s、淡出 43.2–46.6s；`loudnorm I=-16 TP=-1.5 LRA=11`。

### 8. 拼接与压缩（join.py + 编码）
- xfade：transition=fade、重叠 X=1.1、步进 STEP=3.5；13 段总时长 = 3.5×12 + 4.6 = 46.6s；首尾黑场各 1.2s。
- 压码：libx264 preset slow，b:v 10M / maxrate 14M / bufsize 22M，yuv420p；AAC 192k 48k；`-movflags +faststart`；成片约 57MB。

### 9. 验证与交付（verify_final.py）
- ffprobe 规格；blackdetect 确认中间无黑帧；抽帧核对调色/顺序/无漏镜头/音乐起止。
- 只交付成片，不发送中间文件。

## 冷色调滤镜（本次案例值，非固定，按当次要求改）
- 基础：`eq contrast=1.08 saturation=1.2 brightness=0.004 gamma=1.0`
- 色彩：`colorbalance rs=-.03 gs=.01 bs=.04 rm=-.015 gm=.002 bm=.02 rh=-.02 gh=.004 bh=.025`
- 褪色曲线：`curves all='0/0.035 0.3/0.28 0.7/0.74 1/1'`
- 氛围：bloom（split→gblur sigma24→blend screen opacity0.28）+ 颗粒 `noise alls=7 allf=t+u` + `vignette PI/5.2`

## 五轮迭代（用户验收纠偏，值得复用的经验）
| 版 | 做法 | 用户反馈 | 经验 |
|---|---|---|---|
| v1 | 暖调 + 重暗角 + 片头片尾字幕 | 去掉文字、内容单调、调色不好看 | 默认不加字幕；先解决内容多样性 |
| v2 | 清新明亮、无文字、13 个多样镜头 | 画面普通、要氛围感、要滤镜 | 写实≠好看，需要风格化 |
| v3 | 电影青橙 + 胶片褪色/颗粒/bloom/暗角 | 冷色调一点 | 风格方向要按用户偏好微调 |
| v4 | 去暖金、整体青蓝冷调 | 认可，要求调整镜头顺序 | 氛围元素保留、只改色调 |
| v5 | 青蓝河谷 + 隧道移到最前 | 最终交付 | 顺序调整复用片段、不重新调色 |

核心：内容多样 + 风格化氛围 + 色调按用户偏好 + 开场抓眼；每轮只改用户指出的部分，其余保留。
